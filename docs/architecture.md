# 5. Архитектурная схема

Для проекта выбрана модульная архитектура.

Диаграмма построена по коду Mermaid на сайте [mermaid.live](https://mermaid.live).

![Архитектурная схема ИС управления задачами](../img/architecture.png)

Центральным модулем является `TaskModule`. При создании задачи он обращается к `UserModule` для проверки исполнителя, к `ProjectModule` для привязки к проекту. Модуль `AnalyticsModule` собирает данные из всех модулей для формирования сводной информации.
