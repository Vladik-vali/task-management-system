# Тестовая стратегия

## Модульные тесты
* Создание задачи с корректными данными
* Назначение исполнителя
* Смена статуса задачи
* Расчёт просроченных задач

## Интеграционные тесты
* Успешное создание задачи и назначение исполнителя
* Попытка назначить несуществующего пользователя

## Проверка сборки

```bash
dotnet build
dotnet test
```
