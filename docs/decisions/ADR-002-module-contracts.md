# ADR-002. Взаимодействие через контракты

**Статус:** Принято.

## Проблема

Прямое обращение модулей к внутренним классам друг друга увеличивает связанность.

## Решение

Взаимодействие выполнять через публичные интерфейсы и DTO.

## Последствия

**Плюсы:** слабая связанность, проще тестировать.
**Минусы:** необходимо поддерживать DTO и интерфейсы.
