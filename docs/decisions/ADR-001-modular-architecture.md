# ADR-001. Использование модульной архитектуры

**Статус:** Принято.

## Проблема

Необходимо разделить функции системы так, чтобы изменение одной части не затрагивало другие.

## Решение

Разделить приложение на модули: `Projects`, `Tasks`, `Users`, `Analytics`.

## Последствия

* Уменьшается связанность
* Упрощается тестирование
* Возможно независимое расширение модулей
