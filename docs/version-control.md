# Правила ведения репозитория

## Ветки
* `main` — стабильная версия
* `develop` — объединение разработки
* `feature/*` — новые функции
* `fix/*` — исправления
* `docs/*` — документация

## Коммиты
* `feat:` — новая функциональность
* `fix:` — исправление
* `docs:` — документация
* `test:` — тесты
* `refactor:` — рефакторинг
* `chore:` — техническое изменение

## Правила слияния

- Слияние выполняется через Pull Request.
- Слияние `feature/*` в `develop` — через `--no-ff`, чтобы сохранить историю ветки.
- Слияние `develop` в `main` — только для стабильных версий, с созданием тега.
- Конфликты разрешаются вручную с сохранением осмысленной формулировки.
- После слияния ветка `feature/*` удаляется.

## Теги

- `v0.1-git-setup` — настройка Git;
- `v0.2-...` — последующие этапы;
- версии вида `vX.Y.Z` — релизы.
