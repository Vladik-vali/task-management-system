# Назначение и границы проекта

## Назначение системы

Приложение для постановки и контроля выполнения задач. Позволяет создавать проекты, ставить задачи, назначать исполнителей, устанавливать приоритеты и сроки, отслеживать статусы выполнения.

## Границы проекта

### Входит в систему
* Управление проектами
* Управление задачами
* Назначение исполнителей
* Установка приоритетов и сроков
* Отслеживание статусов
* Поиск и фильтрация
* Получение информации о состоянии проекта

### Не входит в систему
* Интеграция с внешними системами (Jira, Trello)
* Уведомления (Email, Push)
* Мобильное приложение
* Диаграммы Ганта
